# B.Tech AI & ML Core Curriculum

## Semester 5: Core Intelligence Foundations
- **AI301: Machine Learning Foundations (4 Credits)**
  - *Prerequisites*: Linear Algebra, Multivariate Calculus, Python Programming
  - *Topics*: Supervised learning, SVM, Decision Trees, Ensembles (Random Forest, XGBoost), Unsupervised clustering (K-Means, GMM), Dimensionality reduction (PCA, t-SNE).
- **AI302: Deep Learning & Neural Architectures (4 Credits)**
  - *Prerequisites*: AI301
  - *Topics*: Feedforward NNs, CNNs (ResNet, EfficientNet), RNNs, LSTMs, Transformers, Attention Mechanisms, PyTorch lab.

## Semester 6: Advanced Intelligence & Systems
- **AI401: Natural Language Processing & Large Language Models (4 Credits)**
  - *Prerequisites*: AI302
  - *Topics*: Tokenization, Word2Vec, BERT, GPT architectures, RAG architectures, Fine-tuning with LoRA/QLoRA, Prompt engineering.
- **AI402: Computer Vision & Edge AI (4 Credits)**
  - *Prerequisites*: AI302
  - *Topics*: Object detection (YOLOv8/v10), Semantic segmentation, Video analysis, Model quantization (INT8/FP16), TensorRT & ONNX deployment.
