# B.Tech — Artificial Intelligence & Machine Learning

## Program Overview

The B.Tech AI/ML program is a 4-year undergraduate program designed to produce industry-ready AI engineers and researchers.

## Duration

4 years (8 semesters)

## Program Structure

### Year 1 — Foundation
- Mathematics for AI (Linear Algebra, Calculus, Statistics)
- Python Programming and Data Structures
- Introduction to Machine Learning
- Computer Science Fundamentals

### Year 2 — Core
- Deep Learning and Neural Networks
- Natural Language Processing
- Computer Vision
- Database Systems and SQL
- Probability and Bayesian Methods

### Year 3 — Specialization
- Advanced NLP (Transformers, LLMs)
- Reinforcement Learning
- MLOps and AI Systems Design
- Cloud and Edge AI
- Research Methods

### Year 4 — Capstone
- Final Year Project (AI/ML)
- Industry Internship
- Electives (Generative AI, Robotics, AI Ethics)
- Placement preparation

## Admission

Based on national entrance examination (JEE/KCET).

## Career Outcomes

- Machine Learning Engineer
- AI Researcher
- Data Scientist
- MLOps Engineer
- AI Product Manager

## Ranking

Students are ranked using the Lyrahub AHP + TOPSIS multi-criteria ranking system which considers CGPA, projects, certifications, research, and extracurricular activities.
