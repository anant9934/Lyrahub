# /plan-only — Specification Only

Invoke **@pm** only. Produce `Technical_Specification.md` for the requirement.

## Rules

- Do NOT hand off to @db, @engineer, @qa, or @devops.
- Do NOT write any code.
- Do NOT run migrations or tests.
- Wait for human review and further instruction.

## Use When

- You want to review a plan before committing to implementation.
- You need to scope a feature quickly.
- You want @pm to flag ambiguities before development starts.
